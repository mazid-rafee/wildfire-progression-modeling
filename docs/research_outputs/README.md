# Curated research outputs (Git-safe copies)

The live experiment trees under `outputs/` are **gitignored** (checkpoints, logs, tensors, rasters).  
This directory holds **curated text copies** of manuscript-facing reports and tables for version control.

Canonical working copies remain under `outputs/...`. Prefer editing there, then re-sync if needed.

**Excluded from this mirror:** `*.pth` / `*.pt` / `*.ckpt`, `*.npz` / `*.npy`, GeoTIFFs, GPU logs, runtime queue PID/ACTIVE noise, and other large binaries.

**External holdout:** Stage A3 cubes were never built; see `v2_external_holdout_feasibility/stage_a3/`.
